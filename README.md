# Command Git dan Github

## 1. Clone project dari github org lain 
command : 
```bash
git clone <url-repository>
```
contoh : 
```bash
git clone https://github.com/tanamataruwara-byte/belajar-git.git
```

## 2. Cara update code 
kita menggunakan command git pull, ini lah yang disebut sebagi "pull"
```bash
git pull
```
>fungsinya adalah untuk mengupdate codingan local kamu, dari hasil code orang lain
